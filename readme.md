# Эмулятор UNIX-подобной командной строки (Этап 4)

## 1. Общее описание

Данный проект реализует учебный эмулятор командной строки с графическим интерфейсом на Python (tkinter). Эмулятор работает с виртуальной файловой системой (VFS), описанной в XML-файле, и поддерживает базовые команды, имитирующие работу в UNIX-подобной среде.

Цель этапа 4 — реализовать основные команды (`ls`, `cd`, `echo`, `cat`, `uniq`), а также обеспечить обработку ошибок и возможность тестирования через стартовый скрипт.

## 2. Описание функций и настроек

### Поддерживаемые команды

#### `ls [путь]`
Вывод содержимого текущей директории или указанного пути.

**Ошибки:**
- `No such file or directory` - если объект не найден

#### `cd [путь]`
Смена текущей директории. Поддерживаются `..` и `/`.

**Ошибки:**
- `No such file or directory` - если объекта нет
- `Not a directory` - если указан файл

#### `echo [строка]`
Выводит переданный текст в консоль.

#### `cat <файл>`
Отображает содержимое текстового файла.

**Особые случаи:**
- Бинарный файл → `[binary data: N bytes]`
- Директория → `Is a directory`
- Отсутствующий файл → `No such file`
- Без аргумента → `missing operand`

#### `uniq [-c] <файл>`
Убирает повторяющиеся строки.

- Без флага `-c` → вывод уникальных строк в порядке первой встречи
- С флагом `-c` → вывод строк с количеством повторов

**Ошибки:**
- `missing operand` - если не указан файл
- `No such file` - если файл отсутствует
- `Is a directory` - если указан каталог
- `Binary file not supported` - если файл бинарный

#### `exit`
Завершает работу эмулятора.

### Параметры запуска

Эмулятор принимает аргументы командной строки:

- `--vfs <файл>` - путь к XML-файлу виртуальной файловой системы
- `--log <файл>` - путь к CSV-файлу для логирования команд
- `--script <файл>` - путь к стартовому скрипту с командами
- `--config <файл>` - путь к XML-конфигурации (альтернативный способ задать параметры)

**Приоритет:** CLI > config.xml

## 3. Команды для сборки и запуска тестов

### Запуск эмулятора вручную

```bash
python emulator_4.py --vfs start_script_min_4.xml --log log.csv
```

### Запуск с тестовым скриптом

```bash
python emulator_4.py --vfs start_script_min_4.xml --script start_script_min_4.txt --log log.csv
```

### Запуск тестового скрипта

```bash
ls
cd docs
ls
cat readme.txt
uniq duplicates.txt
uniq -c duplicates.txt
cd ..
echo Привет из эмулятора
cat file.txt
cat binfile.bin
cat not_exist.txt
cat docs
cd not_exist
cd file.txt
uniq not_exist.txt
uniq docs
exit
```

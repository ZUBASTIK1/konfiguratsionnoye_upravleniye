# Эмулятор файловой оболочки — Этап 3

## 1. Общее описание
Данный проект реализует **эмулятор файловой оболочки** с поддержкой виртуальной файловой системы (VFS).  
На **Этапе 3** реализованы:  
- загрузка структуры VFS из XML‑файла,  
- выполнение команд из скриптовых файлов (`.txt`),  
- логирование всех действий в CSV‑файл,  
- обработка ошибок при некорректных входных данных.  

Эмулятор запускается в отдельном окне (GUI на Tkinter), имитирующем терминал.  
Поддерживаются базовые команды (`ls`, `cd`, `exit`) в виде заглушек, а также демонстрация обработки ошибок.  

---

## 2. Описание функций и настроек

### Основные возможности
- **Загрузка VFS**  
  - Поддержка корректных XML‑файлов (`vfs_min.xml`, `vfs_docs.xml`, `vfs_nested.xml`).  
  - Проверка структуры XML, сообщение об ошибке при некорректном формате (`error_vfs.xml`).  

- **Выполнение скриптов**  
  - Автоматическое выполнение команд из `.txt`‑файлов (`test_min.txt`, `test_docs.txt`, `test_nested.txt`, `test_error.txt`).  
  - Возможность запуска без скрипта для ручного ввода команд.  

- **Логирование**  
  - Все команды и результаты записываются в CSV‑файл (`test_min.csv`, `test_docs.csv`, `test_nested.csv`, `test_error.csv`).  

- **Обработка ошибок**  
  - Сообщение о некорректном XML.  
  - Сообщение о неизвестных командах.  
  - Сообщение о синтаксических ошибках в скриптах.  

### Параметры запуска
Эмулятор поддерживает следующие аргументы командной строки:
- `--vfs <файл>` — путь к XML‑образу виртуальной файловой системы.  
- `--log <файл>` — путь к CSV‑файлу для логирования.  
- `--script <файл>` — путь к скрипту с командами.  
- `--config <файл>` — путь к конфигурационному XML, содержащему все параметры.  

Пример конфигурационного файла `config_baza.xml`:
```xml
<config>
  <vfs>vfs_min.xml</vfs>
  <log>baza.csv</log>
  <script>test_min.txt</script>
</config>
```
## 3. Команды для сборки проекта и запуска тестов

### Запуск вручную
```
python emulator_2.py --vfs vfs_min.xml --log test_min.csv --script test_min.txt

python emulator_2.py --vfs vfs_docs.xml --log test_docs.csv --script test_docs.txt

python emulator_2.py --vfs vfs_nested.xml --log test_nested.csv --script test_nested.txt

python emulator_2.py --vfs error_vfs.xml --log test_error.csv --script test_error.txt
```

### Запуск через конфиг

```
python emulator_2.py --config config_baza.xml
```
### Запуск через bat

```
run_min.bat — тест минимального образа.

run_docs.bat — тест с несколькими файлами и папками.

run_nested.bat — тест вложенной структуры.

run_error.bat — тест обработки ошибок.

run_progon.bat — общий прогон всех тестов подряд.
```

# Shell Emulator (Этап 5)

## 1. Общее описание
Проект представляет собой учебный эмулятор командной оболочки с графическим интерфейсом на Python (Tkinter).  
Эмулятор работает с виртуальной файловой системой (VFS), описанной в XML, и поддерживает базовые команды Unix‑подобных систем.  
Все действия пользователя логируются в CSV‑файл.  

Основные возможности:
- Загрузка виртуальной файловой системы из XML (с поддержкой base64 для бинарных файлов).
- Отображение содержимого директорий и файлов.
- Выполнение базовых команд (`ls`, `cd`, `echo`, `cat`, `uniq`, `chmod`, `exit`).
- Логирование действий пользователя в CSV.
- Поддержка конфигурации через XML‑файл и аргументы командной строки.
- Запуск стартового скрипта с командами.

## 2. Описание функций и настроек

### Аргументы командной строки
- `--vfs <path>` — путь к XML‑файлу виртуальной файловой системы.  
- `--log <path>` — путь к CSV‑файлу для логирования команд.  
- `--script <path>` — путь к стартовому скрипту с командами.  
- `--config <path>` — путь к XML‑конфигу, где можно указать `vfs`, `log`, `script`.

### Основные функции
- **`mount_vfs(path)`** — загружает виртуальную файловую систему из XML.  
- **`log_event(cmd, args, status)`** — записывает команду в CSV‑файл с указанием времени, пользователя, аргументов и статуса.  
- **`mode_to_str(mode, is_dir)`** — преобразует числовые права доступа (например, `0o755`) в строковый вид (`drwxr-xr-x`).  
- **`execute(cmd, args)`** — выполняет команду. Поддерживаемые команды:
  - `ls` — список файлов и директорий.
  - `cd` — смена директории.
  - `echo` — вывод текста.
  - `cat` — вывод содержимого файла (с поддержкой бинарных файлов).
  - `uniq` — удаление подряд идущих дубликатов строк (`-c` для подсчёта).
  - `chmod` — изменение прав доступа.
  - `exit` — завершение работы.
- **`on_enter(event)`** — обработчик ввода команды из текстового поля GUI.  
- **`run_script(path)`** — выполняет команды из указанного скрипта (файл `.txt`).

## 3. Команды для сборки проекта и запуска тестов

### Запуск эмулятора
```bash
python emulator_5.py --vfs start_script_min_5.xml --log log.csv --script start_script_min_5.txt
```

### Пример start_script_min_5.xml

```xml
<vfs>
  <dir name="docs">
    <file name="readme.txt">Это тестовый файл для команды cat</file>
    <file name="duplicates.txt">строка1
строка1
строка2
строка2
строка3
строка2
строка1
строка1
</file>
  </dir>
  <file name="file.txt">Обычный файл в корне</file>
  <file name="binfile.bin" encoding="base64">SGVsbG8gV29ybGQ=</file>
</vfs>
```

### Пример start_script_min_5.txt

```txt
# --- Проверка базовых команд ---
ls
echo "Hello from emulator"
cd /

# --- Проверка cat ---
cat readme.txt
cat image.bin
cat nosuchfile        # ошибка: файла нет
cat docs              # ошибка: каталог

# --- Проверка uniq ---
uniq                  # ошибка: нет аргумента
uniq data.txt
uniq -c data.txt
uniq image.bin        # ошибка: бинарный файл
uniq nosuchfile       # ошибка: файла нет

# --- Проверка cd ---
cd docs
ls
cd ..
cd nosuchdir          # ошибка: нет директории
cd readme.txt         # ошибка: не директория

# --- Проверка chmod ---
chmod                 # ошибка: нет аргументов
chmod abc readme.txt  # ошибка: неверный режим
chmod 644 nosuchfile  # ошибка: файла нет
ls
chmod 600 readme.txt
ls
chmod 700 docs
ls

# --- Проверка echo ---
echo "Тест завершён"
```
### Запуск тестов (используем pytest)

```Bash
pytest -v
```
